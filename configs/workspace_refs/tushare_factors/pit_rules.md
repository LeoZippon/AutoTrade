# PIT 规则（因子重算）

总闸：`record.available_at <= context.inference_at`。
`trade_date`、报告期 `end_date`、文件抓取时间都不能单独替代 `available_at`。

## 默认 08:30

实验默认 `inference_time=08:30`（Asia/Shanghai）。
此时当日日线、当日每日指标、当日复权因子都还不可见。

| 数据 | 本项目保守 `available_at` | 08:30 能用到 |
|---|---|---|
| `daily` | 该交易日 17:30 | 最近一个已收盘交易日 T-1 |
| `daily_basic` | 该交易日 18:00 | T-1 |
| `adj_factor` | 该交易日 09:30（源端约 09:15–09:20 入库） | T-1 |
| 财务报表 / 财务指标 | 公告日 18:00 | 公告日 ≤ T-1 的已公告版本 |
| 宽基指数日线 | 与日线同类，收盘后 | T-1 |

09:25 及更早不得使用当日日频。若把推断改到 15:00 之后，仍须逐行看 `available_at`，不能按「已经收盘」口头放行。

## 复权冻结在 T-1

收益与均线一律用 **T-1 冻结前复权**：

```text
qfq_t = raw_price_t * adj_factor_t / adj_factor_{T-1}
```

`adj_factor_{T-1}` 是推断时最后一条已可见复权因子，盘中不要换成「今天早上尚未发布」的新因子。
不要用供应商 `stk_factor` 的 `*_qfq`：那是从**最新一个交易日**往前复权的历史快照，回看窗口会被未来除权改写。

日收益优先：

```text
r_t = close_qfq_t / close_qfq_{t-1} - 1
```

不要用未复权收盘价的百分比当多日动量。归一化日线里的 `pct_chg` 是除权后日收益，可作 `r_t`，但仍只能用 `available_at` 已放行的行。

## 财务：公告日，不是报告期

TTM = **当时已公告**的最近四个季度相加，不是按 `end_date` 对齐到「那个季度已经结束」。
同一公司同一报告期可能有快报/正式/修订；只保留 `available_at <= inference_at` 的版本，同一公告时点有修订则用修订。
缺字段不要跨版本拼出从未同时发布过的报表。

估值（EP/BP/SP/CFP/DY）的分子用已公告财务，分母用 T-1 可见市值或收盘价。

## 截面排名只对当时可见名字

横截面均值、标准差、分位、Rank，只纳入：

- 决策日已上市且未退市（`universe`）；
- 该因子在本次推断算得出有限值；
- 对应源行 `available_at` 已到。

不要用全历史股票全集、当前上市名单回填，或把停牌/未复牌后仍无可见日线的代码硬塞进排名。
排序后选股必须 `sorted(...)`，不要依赖 `set` 迭代顺序。

## 不要用当日 stk_factor / stk_factor_pro

这两张表按交易日收盘后生产，且前复权锚定「最新交易日」。
默认 08:30：当日行不存在；历史行的 qfq 指标还带未来除权。
MACD/RSI/布林等请用 T-1 冻结 qfq 自己算。

## 计算纪律

- 只读本次 `asof_dir` / `snapshot_dir` 下已确认列；先看 schema 再算。
- 长窗口只取所需列和有限尾窗，不要每个交易日全表重排全历史。
- 模块缓存必须键控 `context.asof_version`；依赖 `inference_at` / `bars` / 账户的值要逐次重算。
- 单位以本次 `data_summary.json` 为准：归一化日线里价格为元/股，量为股，金额/市值为元，`turnover_rate` 与比率为小数（`5%=0.05`）。
- 事件/宏观并集保留来源单位，同名列不能跨表混用。
